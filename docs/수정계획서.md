# 게임 완성도 수정 계획서

> 전제: 태블릿+PC 혼합 · 학급 20~30명 · 최우선 = 네트워크·재접속 안정성
> 결정: 1a(호스트 blip 자동복구) · 2a(강퇴 플래그 분리) · 3a(정전 선생님 토글+기본 완화) · 4b(술래 힌트 미도입, 판정·은신처 정비 우선)

## P0 — 네트워크·재접속 안정성 (1차)

### A-1. 학생 일시적 끊김 자가복구 (self-heal)
- 문제: 잠깐 끊겼다 복구되면 서버에 남은 이전 `onDisconnect`가 내 노드를 지움
  → 클라이언트는 이를 강퇴로 오인해 "연결이 끊겼습니다" 후 초기화면 강제 이동.
- 수정:
  - 강퇴는 전용 플래그 `rooms/{code}/kicks/{uid}=true`로만 판정 (2a).
  - 내 player 노드가 사라졌는데 강퇴 플래그가 없으면 → 즉시 나가지 않고
    로컬 상태로 노드를 다시 써서 조용히 복구하고 게임 계속.
  - 강퇴 플래그 수신 시에만 "선생님이 게임방에서 내보냈어요" 후 퇴장.

### A-2. 선생님(호스트) blip에 학급 전체 리로드 방지 ⚠️치명
- 문제: `onHostLost()`가 호스트 노드가 사라지는 즉시 전원 `location.reload()`
  → 선생님 1초 끊김에 반 전체가 튕김.
- 수정 (1a):
  - 호스트 사라짐 → 15초 유예 타이머 + 작은 토스트만. 학생은 계속 플레이.
  - 유예 내 호스트 노드 재등장 → 타이머 취소, 아무 일 없이 계속.
  - 유예 만료 → 그때만 "선생님과의 연결이 끊어졌어요" 안내 후 초기화면.

### A-3. 태블릿 절전/앱전환 복귀 재동기화
- 문제: 화면 꺼짐/앱 전환 시 탭이 얼어 heartbeat 정지 → offline 판정 → A-1 유발.
- 수정: `visibilitychange`(복귀)·`online` 이벤트에서 즉시
  ① heartbeat 강제 송신 ② meta/players 1회 재조회 ③ 내 노드 없으면 self-heal.

## P1 — 게임 밸런스 (2차)

### B-1. 과학실 정전: 선생님 토글 (3a)
- 기본값 완화: 어둡기 0.08 → 0.12 (30초 주기는 유지).
- 선생님 패널에 "💡 정전 기믹 끄기/켜기" 토글 → `meta.settings.blackout`.
- 연습(오프라인) 모드는 항상 켜짐.

### B-2. 술래 힌트 미도입 (4b)
- 대신 판정 사각·불공정 은신처를 신고 기반으로 정비(발견 시 개별 수정).

## P2 — 전반 점검 (3차, 별도 진행)
- 태블릿+PC 조작 일관성, 30명 성능(원격 30체·위치 10Hz), 온보딩 안내, 연출 폴리시.

## 검증 방법
- 헤드리스 브라우저 + Firebase 모킹 훅으로: 노드 삭제→self-heal, 호스트 삭제→유예
  →재등장/만료 두 경로, visibility 복귀 재동기화, 정전 토글 on/off 동작 확인.
